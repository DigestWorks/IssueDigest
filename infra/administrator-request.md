# 관리자 요청 · 2026-10-13

전용 DB와 기존 자료 조회는 정상 확인했다. 아래는 현재 계정으로 수행할 수 없는 관리자 작업과 접근 정보만 정리한 것이다. 앱 개발·자료 선별·연결기·백업 자동화 구현은 개발자가 진행한다.

## 전달할 내용

1. **pgvector**: 기존 IssueDigest PostgreSQL18.6 환경에 호환 pgvector 패키지/이미지를 준비하고, issuedigest DB에서 vector 확장을 활성화해 주세요. 현재 설치 가능한 확장 목록에도 vector가 없습니다. 기존 DB·볼륨·수집 서비스를 보존하고 버전과 완료 여부를 알려주세요.
2. **앱 계정·백업**: 현재 개발 계정은 DB 소유자지만 새 계정을 생성할 수 없습니다. 앱/worker용 별도 로그인 계정을 준비해 주세요. 테이블·시퀀스 권한은 실제 마이그레이션 후 개발자가 필요한 범위를 정리하겠습니다. 외부 백업 저장소가 있다면 전용 경로와 최소 권한 접근 방법·기존 보관 정책을 알려주세요. 없다면 새로 정할 수 있다고 알려주시면 비용 상한 안에서 준비안을 만들겠습니다. 백업·복원 자동화는 개발자가 구현합니다.
3. **운영·도메인**: IssueDigest에 배정 가능한 자원과 기존 서버의 실제 월 비용/우리 분담액, 기존 웹서버 관리 방식을 알려주세요. issuedigest.projects.ai.kr의 DNS 관리 담당과 연결 방식도 확인 부탁드립니다. 앱 배포 설정과 필요한 DNS/프록시 변경안은 개발자가 준비하겠습니다. 현재 개발 포트를 외부에 바로 열 필요는 없습니다.

비밀번호·키는 대화/공개 저장소가 아니라 서버의 계정 전용 비밀 설정으로 전달해 주세요. 전체 sudo·Docker 관리자·기존 수집 DB 쓰기 권한을 공유할 필요는 없습니다. 위 관리자 작업을 직접 실행하거나 필요한 범위의 운영 절차를 제공해 주시면 됩니다.

## 개발자가 동시에 진행할 일

- 읽기 전용 원문 후보 검사·파일 해시·누락/중복/잘못된 PDF 분리.
- 실제 자료의 출처·원문 대응과 인용 위치 검증, 계약·저장 연결.
- 백업/복원 및 배포 설정의 구현 범위를 별도 설계. 외부 저장소·권한이 준비되기 전에 완료로 표시하지 않음.
- 실제 로그인·초대·TLS·보호 조회가 연결된 뒤 공개 앱 배포. 공개 계획 Sites와 제품 도메인을 구분.
