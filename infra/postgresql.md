# PostgreSQL 연결 준비

2026-10-12. 엔진은 PostgreSQL + pgvector로 확정했다(D011). 현재 저장 코드의 검증 대상은 **전용 합성 DB의 PostgreSQL18.6**이다. 개발 서버에는 DB를 설치하거나 운영 데이터를 변경하지 않았다. 월10만 원 상한 달성·전용 자원 배정은 미확인이다.

## 관리자에게 확인할 항목

1. 기존 서버에서 IssueDigest에 배정할 CPU·메모리·디스크와 월 분담 비용. 기존 수집 서버와의 관계·공존 서비스도 확인한다.
2. 전용 PostgreSQL18.6 인스턴스 또는 같은 버전의 연결 가능한 전용 DB. 앱 계정은 다른 서비스 DB에 접근하지 않으며 마이그레이션 계정과 런타임 계정 권한을 구분한다.
3. API/worker에서 접근할 내부 주소와 DB 이름, 허용 연결 범위. 공개 인터넷에 DB 포트를 노출할 필요는 없다.
4. 외부 백업 저장 위치·보관 기간·예산과 별도 환경 복원 방법. 서버 내부 복사만으로 외부 백업 완료로 기록하지 않는다.

주소/계정/비밀번호가 들어 있는 연결 URL은 개인 비밀 설정으로 전달한다. Git·대화·공개 Sites에 비밀번호를 넣지 않는다. 관리자 확인 전에는 전용 자원이 확보된 것으로 표시하지 않는다.

## 이 작업의 적용 경계

- `packages/storage`는 명시적인 PostgreSQL+psycopg URL을 전달받는 내부 패키지다. 실제 명령과 테스트 조건은 [저장 패키지 README](../packages/storage/README.md)를 따른다.
- 스키마 변경은 Alembic으로 명시 실행한다. API 시작 시 자동 설치/마이그레이션을 수행하지 않는다. 초기 권한·운영 DB migration/rollback은 대상·백업을 확인한 후 별도 작업이다.
- pgvector extension·한국어 분석·임베딩 모델·인덱스는 검색 구현에서 버전/차원/품질을 검증하고 적용한다. 이번 마이그레이션에 사용하지 않는 extension을 설치하지 않는다.
- DBOS system DB와 앱 기준 데이터의 배치·권한은 worker 연결 작업에서 정한다. 두 DB가 자동으로 같은 트랜잭션이 된다고 가정하지 않는다.
- 합성 전용 테스트 DB의 reset/downgrade 증거를 운영 데이터 복구 검증으로 간주하지 않는다. workspace 필터를 사용자 권한 검증으로 간주하지 않는다.
