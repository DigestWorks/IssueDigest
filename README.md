# IssueDigest

DigestWorks의 이슈 조사·근거 비교 서비스 모노레포입니다. 현재는 구현 계획을 검토하는 단계입니다.

첫 사용자는 우리 둘이며, 실제 원자료에서 근거·관계·변화를 찾아 질문에 맞는 화면으로 탐색합니다. 프론트는 React Router, 백엔드는 Python/FastAPI, 그래프는 Neo4j를 사용합니다. 나머지 도구와 운영 배치는 검토 중입니다.
