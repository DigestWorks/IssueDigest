# 메인 화면 재작성

## 문제

메인 화면(`/`)은 지도 기준 스타일 재정의(`intent_design-style-v2.md`) 이전에 만든 화면이다. 흰 배경, shadcn 채팅, 무광 기호 노드, 불투명 압출 지도로 되어 있어 새 스타일과 맞지 않는다. 이 위에 고치면 이전 규칙과 새 규칙이 섞이므로, 기존 홈 화면을 지우고 처음부터 다시 만든다.

## 원하는 결과

새 스타일(어두운 모드 기본, 도면 양식, 홀로그램 층, 주황은 선택·초점에만)로 만든 메인 화면이 `/` 에 있고, 샘플 시나리오 재생으로 다음이 동작한다.

**구성 (민재 결정)**
- 왼쪽: 대화 열. 질문과 답을 「조사 기록」 양식으로 쌓는다. 질문, 답 요약, 탐색 단계(번호), 출처를 도면 양식으로 쓴다. 입력줄과 제안 질문, 색 모드 전환이 있다.
- 오른쪽: 3D 스테이지. 지도·그래프·결과 패널이 한 장면에 놓인다. 바닥 조명, 격자, 아웃포커스, 색수차는 지도와 같다.
- 결과 패널: 3D 공간에 놓이고 카메라 각도에 따라 눕거나 선다.

**온톨로지 그래프 (새 스타일로 다시 만듦, 제안)**
- 노드는 바닥 위의 작은 사각 판을 몇 겹 쌓은 홀로그램 층이다. 맨 위 판 외곽선을 강조한다. 유형은 고정폭 보조 글자(「법안」「의원」…)로 적는다.
- 색은 쓰지 않는다. 탐색 경로 위 노드·관계는 초점 단계, 나머지는 맥락 단계다. 현재 초점 노드는 주황이다.
- 관계는 가는 선이다. 원천 데이터에 명시된 관계는 실선, 모델이 추론한 관계는 점선이다(이벤트에 근거 종류 필드 추가).
- 탐색 순서는 경로 위 노드에 단계 번호(01, 02 …)로 남는다.
- 노드는 바닥 평면 위에서 힘 기반 배치로 놓이고, 선택하면 지도 지역처럼 층 간격이 벌어진다.
- 등장은 점 → 선 → 글자 순서다.

**지도**: `/map` 의 지도를 그대로 쓴다(같은 장면 구성 요소를 스테이지와 공유).

**지우는 것**: `routes/home.tsx`, `chat/`, `stage/stage-view.tsx`, `stage/scene/` 의 기존 캔버스·조명·효과·카메라, `stage/graph/` 의 기존 렌더링, `stage/map/map-layer.tsx`·`compass-ring.tsx`, `stage/panels/`, `stage/hud/`, 채팅 전용 shadcn 컴포넌트.

**남기는 것**: 이벤트 형식, 상태, 시나리오와 재생기, 지도·패널 컴포넌트, 디자인 토큰, `/style`, `/map`.
