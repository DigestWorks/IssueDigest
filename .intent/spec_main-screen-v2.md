# 메인 화면 재작성 — 명세

## 요구사항

- [ ] R1 삭제: 기존 홈 화면 코드(intent 「지우는 것」)와, 그 결과 쓰이지 않게 된 shadcn 컴포넌트를 지운다. `/style`, `/map` 은 그대로 동작한다.
- [ ] R2 배치: `/` 는 왼쪽 대화 열(고정 폭)과 오른쪽 3D 스테이지다. 어두운 모드가 기본이고 대화 열에서 밝은 모드로 전환한다(`?mode=light` 도 된다).
- [ ] R3 대화 열(조사 기록): 질문마다 「질문 | 번호」 머리와 질문, 「답 | 상태」 머리와 흘러나오는 답, 번호 붙은 탐색 단계, 출처 목록을 쌓는다. 빈 상태에는 제안 질문을 보여 준다. 입력줄은 Enter 로 보낸다. shadcn 을 쓰지 않는다.
- [ ] R4 시나리오: 질문을 보내면 맞는 샘플 시나리오를 재생해 스테이지 이벤트와 답 글자를 흘린다. 새 질문은 진행 중인 재생을 멈춘다. 맞는 시나리오가 없으면 근거 부족 상태가 된다.
- [ ] R5 그래프: 노드는 바닥 위 사각 판 층 묶음, 유형은 보조 글자, 색 없음, 탐색 경로는 초점 단계·나머지는 맥락 단계, 초점 노드는 주황, 관계는 명시 실선·추론 점선, 탐색 단계 번호, 바닥 평면 힘 기반 배치, 선택 시 층 간격 확장, 점 → 선 → 글자 등장.
- [ ] R6 지도: `/map` 과 같은 지도 홀로그램(층, 선택 표시, 주석, 틀, 방위 고리, 등장)이 스테이지 장면 안에 나타난다.
- [ ] R7 결과 패널: 3D 공간에 놓이고 카메라 극각에 따라 눕거나 선다(32°/58°, `view-angle.ts`).
- [ ] R8 장면: 바닥 조명, 격자, 거리 감쇠, 아웃포커스(초점 대상 기준), 화면 색수차, 층 색 번짐이 `/map` 과 같은 토큰 값이다.
- [ ] R9 조작: 노드·지역 클릭은 선택, 배경 클릭·Esc 는 해제, 4px 넘게 끌면 회전·이동이다. 선택하면 카메라가 대상으로 옮겨진다.
- [ ] R10 화면 고정 주석: 스테이지 위에 상태·제목(왼쪽 위), 범례·출처(왼쪽 아래), 가리킴·카메라 수치·조작 안내(오른쪽 아래)를 둔다.
- [ ] R11 규칙 문서: `guide.ts` 의 「홈 스테이지 미적용」 표시와 상태를 실제 적용 결과에 맞게 고치고, 그래프 규칙을 새로 적는다. 폐기 목록의 무광 기호 노드를 새 규칙과 연결한다.

## 설계

- 재사용: 지도 장면(`stage/schematic/map/map-scene.tsx`)의 바닥 조명·테마 컨텍스트·후처리·지역 홀로그램, `SchematicPanel`, `primitives.tsx`, 토큰, `events.ts`·`store.ts`·시나리오·`playScenario`.
- 장면 공용 부분 분리: `stage/schematic/scene/` 에 테마 컨텍스트(`ThemeContext`·`useTheme`), 바닥(`SpotFloor`·격자), 후처리(`SceneEffects`, 초점 위치를 함수로 받음), 초점 위치 등록부를 둔다. 지도 장면과 메인 스테이지가 함께 쓴다.
- 지도 홀로그램 분리: `map-scene.tsx` 의 `MapContent` 를 `MapHologram` 으로 내보내 메인 스테이지에서도 쓴다.
- 주석 일반화: `RegionCallout` 의 틀을 `SchematicCallout`(머리 줄, 제목, 값 줄, 출처)으로 일반화하고 지역·노드 주석이 함께 쓴다.
- 메인 화면 코드: `app/main/` 아래(대화 열 `log/`, 스테이지 `stage/`)에 새로 만든다. 라우트는 `routes/main.tsx`(index).
- 이벤트: `GraphEdge` 에 `basis: "explicit" | "inferred"`(기본 explicit) 추가. 상태에 탐색 순서 `trail`(graph.focus 순서) 추가.
- 그래프 배치: d3-force-3d 2차원 시뮬레이션을 바닥(x, z)에 놓는다. 관계선은 실선·점선·경로 세 묶음 형상으로 매 프레임 갱신한다.

## 버린 대안

- 지도 컴포넌트(`SchematicMap`, 자체 Canvas)를 스테이지에 그대로 넣기: 그래프·패널과 한 장면·한 카메라를 쓰지 못한다.
- 기존 `graph-layer.tsx` 고쳐 쓰기: 기존 홈 코드와 섞지 않기로 했다.

## 함정

- `/` 는 미리 렌더되는 SPA 라우트다. three.js 장면은 마운트 후 지연 로드한다.
- 패널 견본(`/style`)은 `useStage` 의 focus 를 쓴다. 메인 화면과 같은 저장소를 쓰므로 페이지 이동 시 상태가 남을 수 있다.
- 점선은 `computeLineDistances()` 를 위치 갱신마다 다시 불러야 한다.
- 지도 경계 데이터는 비동기로 받는다. 등장 기준 시각은 데이터를 받은 시점이다.

- `/map` 이 분리 전과 같은 화면이다(같은 각도 스크린샷 비교).
- `/style` 이 그대로 열린다.
