# 최종 생성 출력의 구조 단순화

2026-10-28 KST. v3 공급자 스키마는 수용됐으나 응답 중 연속 공백이 제한을 초과해 생성이 중단됐다. 원응답과 실패 작업은 보존한다. 날짜 필드와 생성 중단 사이의 인과관계는 확정하지 않았다.

## 범위

- 공백 안전장치·인용 검증·원문·명제·사용량 제한을 유지한다.
- 새 v4 입력과 새 출력 도구에서 필수 요약과 선택 상세(비교·타임라인)를 구조로 구분한다. 요약·비교의 주장에는 날짜 필드를 받지 않고, 타임라인만 날짜를 받는다.
- 자료 참조는 입력 순번으로 받고 서버에서 실제 자료 식별자로 변환한다. 범위를 벗어난 순번과 추가 필드는 거부한다.
- 중복 열 이름·상태 표기를 공유하되 원래 입력으로 정확히 복원해야 한다. 사실·조건·숫자·불확실성을 삭제하지 않는다.
- 기존 v1/v2/v3 읽기와 기본 v1 설정은 보존한다. 저장 계약과 앱 출력은 변경하지 않는다.

## 실행 제한

실제 분석 3건을 재사용하고 최종 생성은 새 요청으로 최대 1회만 더 검증한다. 앞선 실패 최종 v2·v3를 포함해 실제 공급자 요청은 이번 검증 전체 최대 6회다. v3 중단 요청의 확정 사용량은 없으므로 0으로 간주하거나 예약을 환급하지 않는다. 추가 실험을 자동 반복하지 않는다.
