## 판단과 비용

1. 기존 자식 workflow를 기다리며 자동으로 진행한다. 토큰을 영속화하지 않지만 서버 프로세스가 중단되면 동일 요청으로 다시 실행해야 한다. 독립 부모 복구를 구현한 것은 아니다.
2. 전체 대기를 최대600초/자료 수 이하로 제한한다. 정체 루프를 막지만 timeout 뒤에도 이미 접수한 작업이 남으므로 상태 재확인과 같은 요청의 재개가 필요하다.
3. 완료된 모든 영수증을 현재 권한·원문으로 다시 검증한 뒤 반환한다. 추가 AI 비용은 없지만 SQL 재검사 비용이 있고 브리핑·사실 인증은 아니다.
