## Controller 인수와 판단

동일 두 packet/source SHA와 원래 수치·의미 gold를 호출 전에 고정한다. 원문·prompt·raw 응답·usage·모든 resolved field와 relation/null을 직접 검토한다. 사전 검사를 통과하지 못하면 모델 호출0인 실패로 따로 남기고 원래2건의 인수 분모에서 숨기지 않는다. 한계/오해/누락을 그대로 기록하고 실제 예정/불명 양성·다양한 정치 쟁점/중립성·최종 앱은 별도 후속이다.

판단1: 의미 anchor는 한 문장 안의 unique exact phrase, 관계 statement는 연속된 전체 문장 ID로 제한한다. 모델의 글자 번호/occurrence 계산을 없애면서 실제 원문 위치를 보존하려는 선택이다. 반복 문구나 여러 문장에 걸친 의미 근거는 표현하지 못해 누락·전체 거부/유료 실패가 생길 수 있다. 구조상 정확한 anchor도 의미 오연결을 막지 못하므로 직접 의미 평가가 필요하다.
