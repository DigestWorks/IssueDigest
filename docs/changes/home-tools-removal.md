# 이용자 화면의 개발 보조 도구 제거

2026-10-16. 사용자 피드백: ‘연결 확인과 저장된 근거 링크’는 현재 제품 화면에서 불필요하다. 초기 서버 응답 확인과 수동 URL 진입 도구를 제거하고 기존 자료 목록·검색·브리핑의 실제 근거 열기 동작을 유지한다.

## Global Constraints

- 홈/저장한 조사/자료 화면에서 개발 보조 아코디언·연결 확인 버튼·수동 근거 URL 입력을 제거한다. 다른 메뉴나 대체 개발 도구를 추가하지 않는다.
- 제거 도구에만 쓰는 상태·핸들러·import·스타일·테스트를 정리한다. 공용 status/health API와 클라이언트, 직접 근거 URL 라우트, 접근/로그인/실행/초안/테마 동작은 유지한다.
- 자료 목록·검색 결과·브리핑에서 근거 열기와 원문의 인용 강조는 기존 실제 경로를 유지한다. 삭제한 입력 도구의 URL 검증 테스트만 은퇴시키고 직접 라우트/권한/본문 안전성 검증을 제거하지 않는다.
- 백엔드·HTTP 계약·DB·의존성·main/운영은 변경하지 않는다. 실제 사용자/모델/DB 호출 없이 테스트한다. 개인 개발 웹에만 반영하고 기존 Draft PR32를 갱신한다. 사용자의 브라우저 탭은 열지 않는다.

## Task 1: 개발 도구 UI와 전용 코드 정리

- [x] 구현·검증·작업 독립 검토 완료.

Global Constraints가 요구사항이다. apps/web/app/routes/home.tsx의 해당 details 전체와 전용 상태/핸들러/import를 제거한다. styles.css와 evidence/reader.css에서 해당 UI 전용 selector만 제거한다. 관련 README의 현재 기능 설명을 실제 자료/검색/브리핑 동작에 맞게 정리한다. 과거 변경 기록은 지우지 않는다.

개발 보조 UI 제거는 되돌릴 수 있는 작은 변경이므로 삭제된 레이블/selector 부재만 검사하는 새 영구 테스트를 추가하지 않는다(상위 개발 지침). 기존 도구 전용 home/evidence-link 테스트는 은퇴시키되 SSR·세션·질문·자료→근거 실제 탐색과 API 경계 검사는 보존한다. 자료 목록/검색/브리핑에서 근거 열기가 실제 reader 경로와 GET으로 이어지는 기존 회귀 검사를 실행한다. 새 검사가 필요하다면 실제 사용자 흐름의 중요한 회귀만 다룬다. 컨트롤러는 독립 브라우저에서 비회원/인증된 홈·저장·자료에 두 도구가 없음을 확인한다.

Node24.21.0/npm11.19.0에서 전체 JS 테스트·eslint·타입·빌드·계약 검사를 실행한다. 변경 파일만 커밋하며 푸시/원격/배포는 컨트롤러가 한다. 서브에이전트를 만들지 않는다. 보고서는 task-1-report.md에 RED/GREEN, 변경/삭제 범위, 명령 결과와 우려를 남기고 반환은 상태/커밋/검사 요약만 한다.
