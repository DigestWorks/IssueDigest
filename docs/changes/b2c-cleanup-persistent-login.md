# B2C 화면 정리와 로그인 유지

기준: D016·D017과 제품 경험 인터뷰. 사용자가 2026-10-16 승인한 로그인 정책은 최대 14일, 7일 미사용 시 만료다. 동료 접근 허용은 비공개 운영 기록에서 처리한다.

## Global Constraints

- 질문 중심 B2C 브리핑이 제품이다. 팀 작업 공간·자료 등록 관리 화면을 기본 제품으로 제시하지 않는다. 저장된 개발 자료와 조사 실행은 아직 공유 검증 범위이므로 개인 소유 또는 공개 브리핑으로 오인시키지 않는다.
- 현재 저장소 문서를 결정 원본으로 사용한다. 대체된 계획은 활성 문서에서 제거하고 Git 이력과 명확한 보관 기록으로 남긴다. 수집 데이터·인용·읽기·권한·복구 계약은 재사용한다.
- 모든 세션 발급·검증·쿠키·DB 제약은 최대 1209600초, 미사용 604800초 정책을 일관되게 적용한다. 기존 세션을 자동 연장하지 않는다. 활동 시 절대 만료일은 연장하지 않는다.
- Secure·HttpOnly·SameSite=Lax·Path=/·Domain 없는 __Host 쿠키, 무작위 불투명 토큰의 해시 저장, 현재 권한 검사, 로그인 교체·로그아웃 폐기를 보존한다. 자격 증명·이메일·원자료를 공개 산출물에 기록하지 않는다.
- 보안 동작은 실패→통과 테스트와 실제 전용 PostgreSQL로 검증한다. 공유 개발 DB를 테스트 fixture로 초기화하지 않는다. 버튼·문구 등 낮은 영향의 변경에는 구현을 되풀이하는 새 테스트를 만들지 않는다.
- main 병합·운영 게시 없이 개인 개발 환경만 갱신한다. 공개 브리핑 게시·추천·알림·개인 저장을 이 작업에서 완성했다고 표현하지 않는다.

- [x] 기존 마이그레이션은 수정하지 않고 0006 마이그레이션으로 절대 수명 제약을 변경한다. downgrade는 긴 세션을 안전하게 폐기 또는 단축하여 기존 제약을 복구하고, 오래된 8시간 세션의 만료일은 upgrade에서 보존한다.

## Task 2: 기본 제품 화면과 활성 계획 정리

- [x] 헤더 테마·계정 트리거를 테두리 없는 아이콘만으로 바꾸고 접근성 이름·툴팁·키보드·44px 누르기 영역·포커스 표시를 유지한다.
- [x] 기본 홈에서 공동 조사/역할/작업 공간 배지와 기술 세부정보를 제거한다. 단일 공간의 내부 식별자를 표시하지 않는다. 다중 공간의 실제 보안 선택 기능은 숨겨서 임의 공간으로 우회시키지 말고 간결한 자료 범위 선택으로 보존한다.
- [x] 기본 내비게이션은 질문과 브리핑에 집중한다. 독립 자료 관리 페이지와 법안 중심 단축 행동이 기본 서비스를 규정하지 않게 정리한다. 실제 근거 열기·검색·선택·원문 읽기와 저장 실행 재열람은 유지한다. 공유 조사 이력을 개인 브리핑이라고 이름만 바꾸지 않는다.
- [x] 현재 저장 실행/근거 화면의 문구를 브리핑 중심으로 정돈하되, 비회원 질문→로그인→질문 복원과 실제 생성·취소·재접속·권한 경로를 보존한다. 예전 연결 확인·수동 근거 링크 도구는 복원하지 않는다.
- [x] README·AGENTS·docs/README·활성 implementation-plan/requirements-design/tasks의 본문을 B2C 현재 요구·다음 구현·실제 미완료 상태로 재편한다. 기존 완료 상세는 changes/progress/Git 기록으로 연결하고 중복된 옛 작업 공간 중심 미완료 계획은 활성 목록에서 제거한다. 기존 API/근거 계약을 무관하게 삭제하지 않는다.
- [x] 기존 관련 UI 테스트를 새 문구·구조에 맞춰 갱신하고 전체 JS 검사·타입·빌드·계약 검증을 수행한다. 독립 모바일/PC·비회원·인증 사용자·근거 진입 시각 확인은 컨트롤러가 한다.

## 검증·반영 기록

Python2090개(실제 전용 PostgreSQL)·JS493개, 양쪽 린트·타입·빌드·계약 검사를 통과했다. 작업별 검토·전체 변경 독립 검토와390/1440 합성 브라우저의 비회원/인증 사용자·아이콘·테마·질문→로그인·원문/정확 인용·완료 브리핑·후속 질문을 확인했다. 실제 사용자 세션·유료 모델 호출을 대신 생성하지 않았다.

개인 개발 소스 `f545e752f4dab69842c39b0e405b0e70416c6ab6`와0006 제약을 적용했다. 표적 인증 백업 후 기존 세션 만료일·자료/인용·신원 건수를 보존했고, API/워커 재시작·새 정책1209600/604800초·외부 HTTPS200·비회원401/no-store·새 정적6해시와 이전41자산 보존을 확인했다. 실제 배포된390/1440 화면·계정 메뉴·질문→로그인도 확인했다. 적용 중 확인 도구와 실행 명령을 복구한 내용은 진행 기록에 남겼다. main/운영은 변경하지 않았다.

두 번째 개발 초대는 비공개 등록·반복 검증했다. 동료의 실제 Google 첫 로그인/바인딩은 당사자가 확인한다. 기존8시간 쿠키는 자동 연장하지 않으므로 재로그인 후14일/7일 정책을 적용받는다. Sites v54 게시와 문서 사본·이전 계획판v53 보관을 마쳤다. 상세 소스·게시 식별자는 진행 기록을 따른다.
