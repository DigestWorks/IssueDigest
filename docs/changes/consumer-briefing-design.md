## Global Constraints

- 실제 B2C 앱을 수정한다. 질문→30초 브리핑→필요한 비교/변화/정확 인용→후속 질문이라는 기존 여정을 따른다. 과거 작업 공간/자료 선택/UUID/운영 체크포인트 UI·동작 없는 메뉴·샘플 결과·가짜 주목도/여론/최근 이슈·기능 홍보 카드·로그인 유도 문구를 추가하지 않는다. 현재 공개된 실제 목록만 사용하고 기준일을 보존한다.
- 선택한 모바일 브리핑 시안과 ChatGPT의 결과 중심 경험·Linear/Toss의 정돈·Apple의 여백/미감이 기준이다. 절제된 editorial reading 방향: 큰 한국어 산세리프 질문 제목, 넓은 여백, 흰색/깊은 중립색 표면, 소량의 녹색, 정돈된 질문 입력과 공개 브리핑 목록, 여백/선/타입 위계로 내용을 구분한다. 흔한 보라 그라데이션·과도한 카드/그림자/배지·장식용 아이콘·마케팅 문구·새 외부 폰트/이미지/라이브러리는 넣지 않는다. 기존 생성 로고를 사용하고 브랜드도 산세리프 계열로 정리할 수 있다.
- 기존 홈/로그인/공개 브리핑/비공개 질문·진행/저장 기록/원문 drawer를 같은 디자인으로 정돈한다. 두 헤더 버튼은 테두리 없는 아이콘·접근성 이름/툴팁·44px/키보드/초점을 유지한다. 다크모드는 기존 명시 버튼·선택 저장·첫 화면 테마/SSR 방식을 보존한다.320/390/768/1440 폭, 두 테마,200% 확대/긴 한국어/줄바꿈을 고려한다. reduced-motion을 존중하고 정보/조작을 hover에만 숨기지 않는다.
- 비회원 질문은 기존 초안 저장/로그인 이동, 인증 후 편집·명시 제출이다. session/draft/권한/취소/후속/URL/멱등성/리더의 정확 강조·Escape/초점 복원/공개 버전·철회 재검증을 변경하지 않는다. 현재 접수/조사 중 상태를 명확히 표시하며 생성 전 결과/가짜 진행률/AI 부분 결과를 추가하지 않는다. 요청 접수 전/실패/취소·읽기 권한·네트워크 오류 구분을 보존한다. 브리핑 UI는 AI 해석·자료에 기록됨/출처의 주장/확인하기 어려움의 기존 의미를 바꾸지 않는다.
- 변경은 웹 JSX와 CSS에 한정한다. 기존 계약/API/도메인/DB/워커/수집기/AI 모델·지침/유료 checkpoint·공개 게시·예산/세션 정책/의존성/생성 타입/원문 내용은 변경하지 않는다. packages/ui의 타입/렌더링 의미를 바꾸지 않고 앱의 briefing.css로 표현을 맞춘다. 외부 링크/버전/이용 조건을 숨기거나 없애지 않는다. 새로운 저장/알림/관심 이슈 기능은 이번에 만들지 않는다.
- 구현자는 실제 서버/원문/사용자 세션/키/공급자·HTTP를 사용하지 않고 subagent를 만들지 않는다. 합성 HTTP·테스트 데이터만으로 UI를 확인한다. 기존 의미 있는 회귀는 유지하고 단순 스타일/텍스트 스냅샷 테스트를 늘리지 않는다. 새 조건부 UI가 실제 입력/복원/접근성에 영향을 주는 부분만 행동 검사한다. controller가 별도 실제 비회원 브라우저·전체 정적/JS 게이트·독립 검토·정적 웹만 안전 반영·PR·Sites/기록을 맡는다. API/worker/DB/collector·사용자 탭을 그대로 유지하고 main/운영은 병합하지 않는다.

## Controller 인수·공유

작업별/전체 독립 검토와 JS 전체 게이트·합성 UX/실제 비회원 HTTPS를 검증한다. UI만의 변경이므로 Python/DB/유료 검사를 불필요하게 반복하지 않는다. 독립 시각 확인 후 필요하면 구현자에게 한 번 집중 수정하고 같은 범위를 재검토한다. 기존 개인 개발 Nginx의 정적 root를 새 불변 생산 빌드로 원자 전환하며 이전 asset/롤백 경로를 유지한다. 실제 API/worker PID/명령·수집기 source/config/주기·DB·세션/공개 자료를 변경하지 않는다. Draft PR의 실제 반환 번호와 새 Sites 버전·이전 기록·현재 마일스톤을 기록한다. 운영 배포/서버 권한 확대/모델 호출은 없다.
