# 스토킹 질문의 근거 연결

2026-10-28 KST. 현재 질문은 저장 분석까지 완료되지만 검색 가능한 스토킹 자료가 없어 부족 결과를 반환한다.

## 범위

- 기존 수집 DB의 법안 후보는 과거 수집본으로 표시한다. 제안이유·주요내용은 공식 국회 원문과 대조 가능한 자료만 연결하며, 법안 제안을 시행 법률로 설명하지 않는다.
- 현행 법률/시행 예정 조항은 공식 법령 원문과 공포·시행일을 기준으로 구분한다. 기사·AI 요약·운영자 해설을 원문으로 합성하지 않는다.
- 기존 원문·인용·검색 투영·권한 계약으로 명시 편입한다. 원본 capture와 승인/검증 기록은 private에 보존하며 공개 게시·계정·세션·기존 질문 기록은 바꾸지 않는다.
- 일상 명칭과 정식 법률명은 명시한 한정 별칭으로 검색한다. 새 질문 계획만 새 검색 프로필을 사용하고 기존 계획은 재선택하지 않는다.
- 수집/등록/검색 검증에는 AI 호출이 필요하지 않다. 실제 사용자 질문·유료 생성 완료와 검색 가능 여부는 구분한다.

## 편입 내용과 범위

- 국가법령정보센터의 스토킹범죄 처벌법 시행본: 법률 제21998호, 2026-09-29 일부개정·2026-10-02 시행. `lsId=014070` 조회가 같은 버전을 가리킴을 확인했다. 제17조의10제2항의 2027-04-22 시행 예외도 원문과 인용에 보존했다. [공식 시행본](https://www.law.go.kr/LSW/lsInfoP.do?efYd=20261002&lsiSeq=289995).
- 기존 수집 DB의 스토킹 법안 후보 95건 중 22대 의안 2219650·2219697의 공식 국회 제안이유·주요내용을 새로 확보했다. 후보는 과거 수집본이며 이번 편입은 전체 95건의 최신 처리 상태 확인을 의미하지 않는다. 법안 제안문은 시행 법률과 별도 자료다.
- 법령 전체 표현 17,028자와 법안 제안문 573자·557자를 저장했다. AI 입력의 기존 크기 한도를 지키기 위해 법령은 목적·반복성 정의·사건 송치·신변안전·벌칙·시행일 예외의 정확 인용 7개(합계997자)를 선택했다. 모든 조문이 AI 입력에 포함된 것은 아니다. 전문 읽기와 선택한 인용을 구분한다.

## 검증·등록

개별 capture 해시·법령 버전/시행일/표시 URL·국회 의안 대응·정확 인용과 실제 v5 모델 요청의 사전 크기 검사를 통과했다. 등록 계획과 원문 3건을 서버 private 경로에도 보존했다. 공유 앱 DB에서 트랜잭션을 롤백하는 사전 등록·검색 검사를 한 뒤, 검토한 같은 계획을 한 번 반영했다. 검색 3건·다른 작업 공간0건·기존 원문/질문/분석/초대 정보 보존을 확인했다. 모델·최종 생성·공개 게시·계정 변경은 없다.

새 검색은 명시 별칭 `스토킹법`→`스토킹` 주제와 두 공식 약칭을 사용한다. 제한된 질문 표현을 주제 수 제한 전에 제외하여 ‘관련하여’가 들어간 무관한 정책 자료가 선택되지 않게 했다. 기존 v2 코드와 저장 계획은 유지하며, 새 질문 계획에만 `question-legal-aliases-ko-v3`를 기록한다. 이전 부족 결과를 같은 요청으로 재선택하지 않는다.

실제 사용자 질문의 최종 문장 품질·법안 제안 당시 설명과 현재 법률의 정확한 비교는 미검증이다. 이번 검증을 실제 AI 생성 완료로 표시하지 않는다.

## 코드 검증

최종 고정 코드에서 PostgreSQL18.6 전용 합성 DB 3개로 전체 10,983개(Python10,065·프론트918)를 통과했고, 린트·타입·빌드·OpenAPI와 독립 검토를 마쳤다. 처음에는 새 파서의 타입 표기 누락을 수정했고, 중간 검증 중 질문 표현 필터를 보완해 소스 고정 검사가 실패한 기록도 보존했다. 최종 검증은 별도 실행에서 소스 불변을 확인했다. 원문 추출·검색·기존 계획 보존·등록 범위와 실제 AI 문장 품질은 별개다.

## 개발 반영

제품28866c0을 별도 소스로 개발 API에 적용했다. 기존 요청 접수를 잠시 차단하고 프록시의 이전 요청 종료·활성 작업 0건을 확인한 뒤 정상 종료/교체했다. 질문 계획·분석·최종 작업의 전체 행 hash가 교체 전후 동일하며 차단 설정은 원복했다. 기존 실행 환경과 소스는 복귀용으로 남겼다. DB 이관·계정·세션·프론트 자산·main/운영·Actions는 변경하지 않았다.

실제 서버의 새 모듈로 읽기 전용 검색을 수행해 검토한 3건만 선택되고 다른 작업 공간은 0건임을 확인했다. 외부 home/login/health200을 확인했다. 이 검사는 사용자 세션의 질문이나 모델 생성이 아니며 추가 유료 호출은 없다. 이전 계획은 선택 자료를 고정하므로 새 자료를 조사하려면 새 질문 요청을 시작한다.
