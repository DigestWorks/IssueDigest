- Public types: `ScopeKind = Literal["geographic", "population", "institutional", "other"]`; `MeasurementScopeInput` strict model with required `kind` and `anchor: ContextualAnchor`; `MeasurementFactInput(ContextualFrameFactInput)` with required `target_scopes: tuple[MeasurementScopeInput, ...]` maximum 4; `MeasurementFrameInput` with required facts tuple maximum12 and relations tuple of existing ContextualFrameRelationInput maximum16. - `ResolvedMeasurementScope` strict model with required kind and `anchor: ResolvedAnchor`; `ResolvedMeasurementFact` strict model with required candidate_id and target_scopes tuple maximum4. `MeasurementScopeFrame` strict wrapper with literal profile `measurement-scope-frame-v1`, literal status `unreviewed`, required original `input: MeasurementFrameInput`, required `frame: ContextualNumericFrame` and `scopes: tuple[ResolvedMeasurementFact,...]` maximum12. The base frame carries measured object/reporting actor/period/status/tense/relations; scopes align one-for-one with selected facts in original order.
- `build_measurement_scope_frame(source: Source, input: MeasurementFrameInput | dict[str, Any]) -> MeasurementScopeFrame`; `validate_measurement_scope_frame(source: Source, result: MeasurementScopeFrame | dict[str, Any]) -> MeasurementScopeFrame`; public `MeasurementScopeError(ValueError)`. Catch errors at public boundaries and emit fixed sanitized messages with no source/IDs/validation details, no partial results, suppressed exception chaining.
- Validate source/input canonical actual model identity recursively BEFORE any dump/narrowing, using existing `_canonical_models`/`_read`. Reject subclasses/extras/hidden excluded fields/model_construct forgeries, strict bad scalar/container values, wrong versions and non-source reconstruction. Typed subtype MeasurementFactInput must be checked as its declared exact type before adapting via trusted model JSON into existing ContextualFrameInput.
- Strip only new scope field to call build_contextual_frame. Resolve each scope with existing contextual resolver (exact short span; optional explicit sentence-local unique context; repeated/overlapping ambiguity rejected). Each scope must share the selected numeric candidate's citation/quote. Do not require same sentence as number; source may establish scope in another sentence within same quote. Reject identical resolved anchors repeated within a fact even with different kind; distinct exact locations allowed. Do not force scopes different from reporting_actor/measured_entity: same words may legitimately have both roles. No inference of roles from length, morphology, blacklist or hardcoded example words.
- Validator strictly rebuilds entire wrapper from current canonical source and stored input then compares all fields (including ordering, profile/status, nested source hashes/index, all role/scope spans, scope kinds, relations). Any stale/tampered field rejects whole wrapper. Nested frame alone is not this contract and legacy numeric validator compatibility is not claimed.
- Synthetic tests must cover positive mixed scopes, independently nullable reporter, empty scope/facts, 4/12/16 caps, duplicate kind/anchor and quote boundaries, repeated short text with explicit context, overlap ambiguity, source drift/identity and every wrapper component tampering, strict/canonical forgery (including malicious dump), no I/O, sanitized errors. Include two same measured objects with different geographic/institutional scopes and operator without explicit reporter; also show structurally valid wrong semantic classification remains unreviewed. Do not use private source IDs/questions/quotes or imply synthetic hand-authored frames were AI-generated. Preserve old tests and handle import reload isolation only for modules introduced by new tests.
