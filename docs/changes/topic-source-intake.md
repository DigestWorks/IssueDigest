# 공식 제안문 주제 범위 확대

2026-10-28 KST. 스토킹 중심 검색 외에 기존 수집 데이터에서 답할 수 있는 주제를 넓힌다. 새 제품 코드/스키마/수집 runtime은 만들지 않고 검증된 국회 연결기·원문/인용·명시 등록을 재사용한다. OpenSpec root=null, 초기화하지 않는다.

## 범위와 선정

기존 읽기 전용 MySQL의22대 법안명에서 전세사기·국민연금·개인정보를 검색해 각2건을 제안일/의안번호 순으로 선별했다. 후보의 제안일은2026-04~07월이며 최신 전체 목록이나 현재 처리 상태로 설명하지 않는다. 공식 제안이유·주요내용을 새로 확보해 대응을 확인한 건만 최대6건 private 검색에 추가한다.

기존 gpt_summary/모델 산출물·처리 이력·여론·찬반·시행 효력은 원문으로 가져오지 않는다. 제목에는 '의안 번호·제안문'을 표시하고 법안 제안을 시행 중인 법률로 합성하지 않는다. 공개 브리핑 자동 게시·추천·최근 이슈 UI는 추가하지 않는다. 예시 질문은 제안 내용에 한정하며 실제 AI 생성 품질 확인과 구분한다.

## 절차·경계

- 공식 국회 고정 origin/한 건2요청의 기존 capture를 최대6건에 한 번씩만 실행한다. TLS·크기·ID/form/CSRF·원문 추출 가드를 유지하고 자동 retry0이다. 실패는 제외로 남긴다. 유료 AI 호출은 없다.
- 기존 준비 도구로 원본 capture hash·식별자/제목/번호 대응·전문 표현·정확 인용을 구성한다. 질문별 실제 v5 입력 사전 크기 검사를 통과해야 한다. 제목이나 과거 메타데이터로 원문을 합성하지 않는다.
- 새로운 private 계획/원문/hash를 보존한 뒤 독립 검토한다. 원본 DB/파일·실행기는 읽기 전용으로 둔다.
- 개발 DB의 사전 백업을 private으로 보관하고 아카이브를 검사한다. 명시 check는 트랜잭션 rollback하며 원문·검색 투영·기존 질문/분석/최종/초대 행 불변을 확인한다. 같은 고정 계획만 한 번 append하고 재조회한다. 기존 행 덮어쓰기·계정/권한·질문 재선택·앱 프로세스 교체를 하지 않는다.
- 실제 검색/다른 범위0건과 원문 읽기·정확 인용을 확인한다. 새 질문에서만 활용되며 기존 계획을 바꾸지 않는다. 수집/검색 성공을 실제 사용자 최종 문장 품질이나 지속 수집 완료로 표시하지 않는다.

## 보존·검사·실제 적용

개발 DB의 일관 스냅샷 full/public archive를 전후 보관했고 public 스키마27테이블을 각각 별도 소유 DB에 복원해 원본 rowhash/count 일치를 확인했다. full archive 목록도 검사했다. 역할/vector/DBOS까지 포함한 완전 재해복구 검증은 아니다. 첫 백업은 이전 로컬 이미지ID가 없어 실제 dump 전에 실패했고, 실패 파일을 보존한 뒤 현재 PostgreSQL18.6 클라이언트를 검증해 새 실행에서 완료했다.

실행기 검토에서 주제 매핑·실행기 코드 해시를 승인/check/현재 파일에 결합하고 항목별 sourceID/의안번호 대조·기존 행 중복 수 보존을 보강했다. 보호 검사9개·기존 연결기/준비 관련204개와 독립 검토를 통과했다. 앱 코드는 변경하지 않아 기존 전체 검사를 새로 실행했다고 표시하지 않는다.

check는 rollback했고 같은 고정 계획을 한 번 적용해5건을 생성했다. 발견한 public 스키마27테이블 중 원문/인용·검색 등 허용된10테이블 이외의 테이블은 완전 불변이며, 허용 대상의 기존 행도 보존했다. 질문/분석/최종·계정/세션·공개 브리핑을 바꾸지 않았다. 원본6capture·계획/승인/check는 private 서버에도 해시와 함께 보관했다.

실제 실행 환경의 코드/설정으로 저장된5개 bundle/presentation의 정확 일치와 주제별 검색·다른 범위0건을 읽기 전용 확인했다. 외부 home/login/health200도 확인했다. 이는 사용자 원문 HTTP API나 로그인/실제 AI 생성 검증은 아니다. 앱 프로세스·모델·프론트·수집 실행기·원본 MySQL·main/운영·Actions를 변경하지 않았고 유료 모델 호출0이다. 소유 복원/테스트 컨테이너1개만 정리했다.

## 검색 품질의 남은 범위

주제어 단독은 전세사기1건, 국민연금2건, 개인정보3건을 반환하며 편입한 자료를 모두 포함했다. 개인정보의 추가1건은 기존 스토킹 시행본으로 교차 주제 검색이며 무관하다고 단정하지 않는다. `주제 관련 법안은 무엇을 제안하나요?`처럼 공통 단어가 들어간 질문은 최대5개 후보를 반환해 다른 후보도 섞인다. 새 예상 자료 포함 수와 총 후보 수를 따로 기록했다. 관련성·약칭/공통어 처리를 더 개선해야 하며, 검색에 포함됐다는 사실을 AI 문장의 타당성이나 최신성 보증으로 표시하지 않는다. 이전 질문 계획은 고정하므로 이 자료는 새 요청부터 검색된다.
