## 확인한 원인

개발 앱의 분석 작업은 완료됐다. 읽기 전용으로 현재 자료·저장 분석·최종 입력 패킷 무결성을 검증했고, 최종 생성 사전 검사가 질문에 연결된 근거 0건을 발견했다. 이 검사가 일반 실행 오류로 전달됐다. 현재 검색 단위에서 스토킹 관련 내용은 0건이며, 관련 법령의 부재를 모델 추론으로 메우지 않는다.

## 동작 계약

- 저장된 분석을 현재 원문에 대조해 검증한다. 유효하되 질문에 연결된 명제가 없으면 기존 `blocked` 응답으로 종료한다.
- 이 경우 최종 모델 호출·최종 job 예약·enqueue를 하지 않는다. 기존 분석과 사용량은 보존한다.
- 연결된 근거가 있으면 기존 최종 생성 경로를 따른다. 변조·출처 변경·잘못된 분석은 정상 부족 결과로 바꾸지 않는다.
- 화면에는 현재 자료로 답할 근거가 부족함을 알린다. 연결 오류나 다시 확인하라는 문구로 위장하지 않는다.
- 기존 API 응답 형식·최종 생성 가드·세션·권한·모델·비용 한도는 유지한다.
