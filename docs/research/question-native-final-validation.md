## 구현

기존 Sol 전용 저장·실행·최종 SDK에 Astra/v5 지원을 추가했다. 최종 결과가 실제 요청한 모델을 기록하고, 근거 작업·최종 작업·저장 영수증의 모델이 모두 같아야 한다. Astra 예약은 각 단계 최소1달러다. 기존 Sol의 근거v2/v3/v5·최종v1, 낮은 예약, 요청 bytes·identity·워크플로·재생은 보존한다.

migration0015는 기존 제약 형태를 확인한 뒤 두 모델 허용과 Astra 예약 조건을 적용한다. Astra 행이 있으면 downgrade를 거부한다. 현재는 격리 검증 DB에만 적용했고 공동DB·기본 모델·현재 개발 앱·main/운영은 바꾸지 않았다.

저장 태스크의 독립 검토에서 발견한 재접수/완료 재처리의 입력 identity 재검증 누락을 회귀 검사 후 수정했다. SDK·실행 태스크의 독립 검토는 추가 지적 없이 통과했다. 관련273개 검사와 모의 native 분석→최종 ANSWER→SQL 저장·전체 reader JSON 일치·같은 요청 재접수 추가0을 확인했다. 기존 Sol/v2·v3 wire fixture는 원래 보존본과 byte가 같다.

## 해석 경계
