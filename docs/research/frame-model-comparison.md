# 수치 프레임 · 모델 제한 비교

2026-10-20. [SDK 실제 인수](numeric-frame-generation-acceptance.md)의 gpt-5.4-mini 결과(부분1/거부1·의미0/2)를 기준으로 같은 계약의 상위 모델 추가 효용을 확인한다. 실행 코드 변경 없이 새 연구 기록만 추가한다.

## 호출 전 고정 프로토콜

- 비교 모델은 공식 문서에 공개된 고정 snapshot `gpt-5.4-2026-03-05`다. 최신 전체 모델의 우열/운영 기본값 선정이 아니라 알려진 두 실패의 제한 비교다.
- 기존 source packet2개·semantic-reference 원본·지침3274UTF8·prompt/schema·SDK sourceefa9bf2·출력2500/총20000/30초·no-store·SDK/client retry0는 그대로다. 바꾸는 것은 모델뿐이며 reasoning effort는 기존 SDK처럼 별도 지정하지 않는다. GPT-5.4 문서상 기본은 none이다. 모델별 서버 기본/토큰화 차이는 남는다. Mini는 이전 alias의 저장 응답이고 비교군만 snapshot으로 고정해 시점/샘플링 변동까지 통제한 무작위 실험은 아니다.
- 각 자료1회·신규 총2호출 상한이다. 성공까지 재호출/다른 모델 fallback·출력 수리·gold/기준 사후 수정은 없다. 접근 불가/시간초과·거부도 그대로 기록하며 미상 usage는 무료로 보지 않는다.
- 원래 mini 응답은 재호출하지 않고 저장된2결과/known input6730/output1738을 비교한다. 같은 실패를 이미 아는 단일 annotator의 개발 표본이지 holdout/독립 의미 검증이 아니다.
- raw 모든 역할/null/관계와 실제 candidate ID를 현재 index에 대조한다. 반환/거부·사전 기준 충족·유효한 다른 표현의 차이·실제 의미 오류를 구분한다. 신규 응답/usage/시도·기준 hash는 private에 보존하며 SDK hash는 실행 서명이 아니다.
- 후보/대상·발표자·상태/시제·조건/전망 근거·비교 기준·필수 직접 포함 관계가 판정 기준이다. 후보6/5만 세거나 거부 raw를 수용 성공으로 집계하지 않는다.
- 문서 변경 시1회 가공하는 파이프라인 후보로 평가한다. 앱 요청/월 예약·DBOS/권한·캐시·최종 브리핑과 앱 배포는 변경하지 않는다. 의미가 좋아져도 앱 인수/정치 중립성/전체 출시 완료를 뜻하지 않는다.

## 비용 기준

공식 Standard text 요율에서 GPT-5.4는100만 토큰당 입력$2.50/캐시입력$0.25/출력$15, mini는$0.75/$0.075/$4.50다. 캐시 없이 동일 토큰 수라면 약3.33배지만 실제 토큰/지연은 다를 수 있다. 이번 입력은272K 미만이며 reasoning 토큰도 출력 비용에 포함된다. 출력/총량 상한은 유지하고 비용은 raw 관측 토큰으로 계산한 참고 USD와 실제 청구액을 구분한다. 환율/세금·지역/우선순위 등 청구 설정은 검증하지 않는다.

[GPT-5.4 모델·snapshot/기본 reasoning/지원 기능](https://developers.openai.com/api/docs/models/gpt-5.4), [공식 요율](https://developers.openai.com/api/docs/pricing). 2026-10-20 확인. 문서의 이용 가능성은 해당 API 키의 권한을 보장하지 않는다.

## 결론과 다음 작업

같은 계약에서 모델 역량 차이로 일부 역할·관계 오류가 줄었다. 하지만 구조 반환률은 그대로1/2이고, 단 두 개발 표본으로 일반 정확도나 운영 기본 모델을 정하지 않는다. 이번 GPT-5.4는 같은 계열의 mini 대비 효용을 보기 위한 비교군이며 최신 모델 전부의 비용/성능 최적 모델이라는 뜻이 아니다.

다음은 반복 표현의 어느 위치를 뜻하는지 원문에 결합해 명시 선택할 수 있도록 참조 계약을 설계한다. 서버가 임의로 첫 번째/가장 가까운 표현을 택하거나 자동 수리/추가 유료 요청으로 이번 실패를 덮지 않는다. 별도 미관측 자료와 엔티티 정규화·수준/증감 관계 의미·중립성·전체 앱 예산/캐시/권한/복구 인수는 남는다. 현재 앱/개발/운영 배포0·D013 유예를 유지한다.
