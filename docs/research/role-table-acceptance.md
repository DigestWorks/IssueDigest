## 사전 판정 기준

기존 평가의 기준/원래 gold/응답을 읽기 전용 보존하고 새 검수 응답 전에 기대 진단을 비공개 고정한다. 단일 에이전트의 전체 원문 대조이며 독립 사람 정답으로 표시하지 않는다. 역할 저장 위치만 다르고 정보가 실제 남아 있으면 중복 누락을 강제하지 않는다. 각 명시 대상별 hard 탐지·미탐·추가 hard·uncertain·미완료·구조 거부를 구분한다. 추가 hard는 전체 원문·원래 proposal과 대조해 근거 있는 추가 발견/명확 오탐/판정 유보로 나누며 무조건 오탐으로 세지 않는다.

- G: 필수3수치와 프로그램 구성 한정어는 원래 결과에 남아 있다. 목표 기간 공동 적용/역할 분류는 독립 사람 재판정 전 유보한다. 새 무경고를 정상 정확도 분모로 쓰지 않으며 분쟁 진단은 별도 표시한다. G는 전체5건/비용/완료 분모에서 제외하지 않는다.
- H: 국비 수치n3의 세 하위 수혜 지역 누락을 missing target_scope로 찾는지 확인한다. 사업 연도는 다른 역할에 남아 있어 period 중복 누락으로 강제하지 않는다. 사업 수n2는 지역명이 한 anchor에 묶여 있으나 이름은 남아 있으므로 명칭 누락으로 세지 않는다.
