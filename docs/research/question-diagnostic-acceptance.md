2026-10-27. 기존 실패는 불변으로 보존하고, 같은 사전 고정 원문·질문·의미 기준으로 별도 시도를 준비한다. 제품 코드·모델·지침·검증 규칙을 바꾸지 않는 비공개 제한 검증이므로 문서/연구 예외를 적용한다.

## 실행 전 기준

- 자신의 새 로컬 PostgreSQL18.6과 합성 신원·세션만 사용한다. 공동 DB·실제 사용자 로그인·개발 실행기는 조작하지 않는다.
- 현재 제품 소스와 입력·기준·검증 도구를 해시로 고정한다. 모의 실행으로 저장·재열람·중복 요청 방지를 먼저 확인하고 별도 검토 후 실행한다.
- 기존 모델·시간·토큰·각 단계$0.50 예약을 유지하며 분석1회·최종1회 이하, 재시도0이다. 송신 불확실성도 시도 소진으로 기록한다. 실패 후 자동 보정·추가 호출·한도 확대는 없다.
- SDK가 실제 읽는 응답 스트림만 비공개 파일에 제한 크기로 복사한다. 키·요청 헤더는 보관하지 않는다. 응답을 미리 읽거나 제품의 수용 조건을 바꾸지 않는다. 부분 수집과 완전 수집을 구분한다.
- 모델 완료·구조 수용·SQL 저장·재열람·사전3명제 의미 보존을 구분한다. 다른9개/전체12개 기준의 분모와 과거 결과를 바꾸지 않는다. 비맹검 단일 자료이며 진실·중립성·일반 품질 인증이 아니다.

비공개 수집 도구의5개 합성 검사를 통과했다. 별도 검토에서 지적한 수집 상태 누락을 보완해 잘림·쓰기 오류·스트림 소진/닫힘을 기록한다. 이전 모의 결과를 보존하고 새 해시로 최종 모의2요청·SQL 완료 재열람·동일 요청 추가 호출0을 확인했다. 독립 검토 C0/I0/M0 후 소유 DB를 초기화하고 신규 실제 시도는 아래 결과로 종료했다. 의미 품질 성공은 아니며, Sites 요약의 게시 상태는 진행 기록을 따른다.

## 신규 실제 결과

신규 분석1회에서 response.completed·입력2,444/출력2,785/합계5,229토큰을 관측했다. DTO 구조 검사는 통과했지만 원문 연결 검사 evidence_contract에서 거부됐다. SQL은 failed/output, usage_complete=true, stream_closed=true이고 최종 브리핑 작업은0이다. 이번 시도의 추가 송신·재시도·필드 수리·한도 변경은0이다. 예약$0.50을 보존했으며 실제 청구액으로 표시하지 않는다. 과거 시도와 합산 성공률을 만들지 않는다.

오프라인 재현에서 최초 거부는 ‘선언한 위치의 원문이 인용문과 다름’이었다. 참조 등장20개(고유15개)의 인용문은 모두 해당 원문에 존재하지만 선언한 시작/끝 위치가 실제보다9글자 앞섰다. 새 응답의 위치 오류는 확인했지만 과거 원응답을 수집하지 않은 시도도 같은 원인이었다고 단정하지 않는다. 원문·질문·제품537파일과 기준 해시는 유지한다. 응답 원문/키/자료 ID/실제 질문은 공개하지 않는다.

수집된 스트림은413,812bytes·JSON 이벤트1,299개이며 완료 이벤트와 닫힘을 관측했다. 수집 잘림/쓰기 오류는 없고 파일 크기는 기록값과 같다. SDK는 완료 이벤트에서 읽기를 멈췄으므로 end_of_stream=false다. 제공자의 전체 연결 내용을 끝까지 수집했다고 표시하지 않는다. 정확한 완료 응답의 인자와 원래 검증기를 사용해 추가 네트워크 없이 같은 거부를 재현했다.

사전3명제의 의미 보존과 최종 생성/저장/재열람은 미평가다. 인용문 텍스트 존재와 위치 오류 진단을 사실성·중립성·질문 답변 성공으로 해석하지 않는다. 사용자의 실제 로그인·개발 주소 SSE/UI 인수도 남는다.
