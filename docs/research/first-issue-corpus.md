## 이용·파싱 경계

공공누리 표시는 해당 게시물에서 확인했다. 텍스트 추출은 사진·이미지·캡션·외부 링크·스크립트를 제외한다. 공공누리1유형은 [출처표시 조건](https://www.kogl.or.kr/info/license.do)을 따른다. 사이트가 공개되어 있다는 이유만으로 이용 허용을 부여하지 않는다.

법령 조문은 [저작권법 제7조의 법령 범위](https://law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0007&lsiSeq=283335&urlMode=lsScJoRltInfoR)에 한정해 보관한다. 생활법령 해설·편집·이미지·민간 기사 전체에 같은 판단을 확장하지 않는다. 장학재단 공지·PDF/통계 자료 등의 본문 이용 조건은 미확인 상태를 유지한다.

HWPX 연구 추출은 제한된 ZIP/XML의 말단 문단 텍스트를 읽었다. 실행 중인 수집 패키지의 HWPX 파서는 아니다. 표의 행/열·병합·단위 연결과 이미지 자료는 복원하지 않았다. 법령은 확보한 조문만 읽었으며 다른 조문을 포함한 완전한 법령 파싱 결과가 아니다.

## 다음 연결

1. 확보한 HWPX의 본문·표·출처 표시를 생산용 파서와 기존 EvidenceBundle에 연결하고 회귀 검증한다. 핵심 조건과 예산 비교의 자료 위치를 검토한다.
2. 이해관계자 직접 성명·국회 회의록·심의 자료와 정확한 등록금/장학금 통계 파일을 확보해 별도 가족·시점으로 추가한다. 재사용 미확인 자료는 모델 입력에서 제외한다.
3. 검토한 자료와20개 질문으로 동일 조건의 이름/한국어 어휘·벡터·기간/출처 검색을 비교한다. 생성 답변의 근거·보류·수치를 각각 평가한다.

현재는 조사·파일/문서 준비이며 실제 공동 DB 등록·검색 API·AI/생성 화면 실행·공개 앱 배포는 미완료다. 앱 접속 설정·백업 확인 대기와 독립적으로 진행했다.

## HWPX 파서 후속 확인 · 2026-10-14

앞 표와 출처 TSV는 첫 조사 커밋의 상태를 보존한다. 이후 [HWPX 구현](../changes/hwpx-evidence.md)에서 S036·S034·S001의 구역 순서·표34개·셀278개의 행/열/병합 범위를 실제 XML과 대조했다. 기존 근거 계약의 셀/텍스트 인용281개와 별도 검증 DB의 저장·재실행·동일 조회도 확인했다. 공식 HTML3개에 HWPX3개가 더해져 파서 검증 자료는6개다. 공동 DB에 등록하거나 수집 worker/화면을 연결한 것은 아니다.

새 파서는 원문 단위·기간 문구를 셀 텍스트에 보존하고 추정 메타데이터를 만들지 않는다. 첫 연구 추출과 정규화 버전/텍스트/위치가 다르므로 이전 인용 후보를 그대로 새 표현에 옮기지 않는다. 새 표현의 위치를 다시 검증했다. 학교별 자격·예산 포함관계·단위의 의미 검토, 적격30~50개 확보와 검색/AI 평가 실행은 후속이다.
