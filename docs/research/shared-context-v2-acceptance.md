## 다음 작업

현재 v2 경로의 앱 적용을 보류한다. 단위·근사 누락과 구조 반환은 보완했지만, 명시 범위 누락·행위 주체의 대상 범위 오인과 짧은 다문단 요청의 용량 제한이 남았다. 지침 추가나 모델/출력 상한 증액만으로 해결된다고 가정하지 않는다.

다음 설계는 수치별 적용 범위의 명시 근거와 행위 주체를 구분하고, 누락뿐 아니라 근거 없는 추가도 검사하는 계약과 요청의 중복 구조/용량을 함께 검토한다. [그룹 출력 제안](../changes/measurement-group-output.md)은 같은 범위의 입력 중복을 줄일 수 있지만 서로 다른 측정 대상의 범위 연결·주체 오인까지 해결한다는 증거는 없으므로 자동 채택하지 않는다. 후보 계약·합성 회귀·원문 전체 용량을 검증한 뒤 새 사전 기준의 제한 의미 인수와 전체 앱 비용/권한/내구 실행을 거쳐 반영을 판단한다. 원래 결과를 수정하거나 자동 상속·사후 수리로 성공 처리하지 않는다.

기존425개 실행/설정 파일과 이전121개 실제 증거는 불변이다. 새 원문/기준/전송/응답/판정은 별도 비공개 불변 manifest에 보존했다. 실행 코드는 바꾸지 않아 전체7,206개 검사 증거를 재사용하고, 이번에는 문서·링크·비공개값 제외를 새로 확인한다.
