## 확인한 동작

새 입력의 모든 참조는 citation_id/text만 받는다. 동일 citation 안에서 정확히 한 번 나타나는 문구만 Unicode code-point 위치로 변환한다. 중첩 출현·누락·정규화 차이·빈 문구·없는 citation·오프셋/발생 번호 주입은 거부한다. 여덟 facet 구조와 상한·strict/frozen/변조/잘못된 원문 형태·변환 중 원문 변경을 검사한다. 기존 명제 포함/연결/불확실성·coverage/순환 검증을 유지한다.

TDD red 후 신규56개·관련603개를 통과했고 scoped Ruff/strict mypy를 확인했다. 합성 검사 중 빈 의존성 배열을 상한 데이터로 늘리는 테스트가 DTO 호출 전 IndexError를 내어 fixture만 보완했다. 해당 상한은 최대8/초과9를 직접 검사한다. 제품 수용 조건은 변경하지 않았다.
