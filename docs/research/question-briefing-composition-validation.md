## 범위·한계

순수 미검토 조합 계약이다. 실제 최종 모델 요청·그 모델의 의미 품질·영속 저장/API/UI 연결·개발 적용은 아직 인수하지 않았다. 자유 문장과 날짜의 의미는 참조 검사만으로 검증되지 않으며 coverage는 원래 모델이 선택한 명제의 범위다. 모든 실제 관련 사실을 빠짐없이 찾았다는 인증이 아니다. 입력 영수증은 별도 인증 서명이나 현재 권한 승인으로 쓰지 않는다. 제안과 파생 문장을 함께 일관되게 교체하면 다른 유효한 미검토 제안이 될 수 있다. 재구성 검사는 출처·구조 일관성 검사이며 기록의 인증/불변성은 향후 저장 계층에서 보호해야 한다. 하위 renderer는 문자열을 안전하게 표시해야 한다.

같은 질문·원문·영수증·제안에서 결과가 결정적이며 저장 후보는 전체 재구성 비교로 변조를 거부한다. 새 provider/client·DBOS 등록·공개 게시·운영 변경·앱/기본 worker/main 활성화는0이다. 외부 통신 없는 라이브러리이며 실제 비공개 자료를 테스트에 복제하지 않았다.

## 판단과 비용

1. 원래 명제·조건·미반영 coverage를 함께 보존하고 모든 자유 문장을 미검토로 유지했다. 인용은 의미 인증이 아니므로 실제 모델 품질 검증이 남는다.
2. 역사 Canvas 버전을 재사용하지 않는 별도 조합 profile을 사용했다. 구형 화면에 즉시 연결되지 않으며 최종 생성·저장·표시 연결이 남는다.

PR·Sites 및 QA 정리의 최종 인계는 이후 저장소 진행 기록을 따른다. Sites는 별도 시점의 정확 사본이며 저장소가 원본이다.
