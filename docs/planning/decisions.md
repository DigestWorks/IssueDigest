## D011 · 저장·검색·실행 엔진 확정 (2026-10-12)

사용자가 **PostgreSQL + pgvector + PydanticAI/DBOS**를 선택했다. A001~A003의 추천을 채택하며 PoC와 운영에 같은 엔진을 사용한다. 선택은 실제 한국어 검색 품질·중단 복구·월 비용 검증의 완료를 의미하지 않는다. 인증·운영 배치는 별도로 남긴다.

첫 구현은 [원문·인용 저장 기반](../changes/postgres-storage.md): PostgreSQL 18.6에 검증된 계약·불변 스냅샷·outbox를 한 트랜잭션으로 저장한다. 파일 원문, 검색 인덱스, Neo4j 투영, PydanticAI/DBOS 워커는 후속이다. 현재 의존성에 사용하지 않는 실행 프레임워크를 먼저 추가하지 않는다.

근거와 이관·한국어 검색·복구의 확인 기준은 [엔진 선택 기록](../research/engine-selection.md)에 둔다. 아래 이전 선택지는 당시 비교 이력으로 보존한다. 현재 후보로 다시 제시하지 않는다.

## D013 · 공개 앱 배포 유예 · 2026-10-13

사용자는 최소 수준에 도달할 때까지 배포를 연기하고 개발을 계속하도록 요청했다. DNS·HTTPS와 main 자동 배포 설정은 보존하며 이번 개발에서 main 병합·공개 앱 게시를 수행하지 않는다. 공유 계획 Sites는 진행 기록 공간으로 계속 갱신한다.

첫 공개 판정은 기존 R1~R6과 PoC 품질 기준으로 한다. 두 사용자가 실제 첫 이슈 자료의 원문·근거를 읽고 조사 질문에 대한 AI 결과를 저장·같은 결과로 재열람하는 흐름, 접근 거부·자료 부족·오류/로딩·인용·비용 제한을 검증한다. 초기 빈 화면이나 개별 라이브러리 검사 통과만으로 게시하지 않는다. 이미지 도구 등 확장 기능 전체를 첫 배포의 선행 조건으로 추가하지 않는다. 이번 저장 근거 읽기 화면은 이 흐름의 부분 구현이다.

## D014 · 첫 검증 이슈 선정 · 2026-10-13

사용자가 최근 시사를 검색해 선정하도록 위임했다. 첫 주제는 지방국립대 등록금 지원의 대상·재원·형평성이다. 공식 예산안 설명과 최근 국정감사 발언/제외 대상 논쟁을 확인했고, 선정 이유·대표 질문5개·출처 시작 목록·이용/평가 경계는 [첫 이슈 기록](../research/first-issue.md)에 남긴다. 선정 완료와 실제 원문 수집·이관·AI 답변 평가 완료를 구분한다.

## D015 · Google 로그인·명시 초대 · 2026-10-13

사용자가 OAuth 로그인과 Google 제공자를 선택했다. 앞서 제시했던 GitHub 로그인 제안은 대체하며 당시 후보 계정은 등록하지 않는다. 이 결정 당시 승인 계정은 한 개였다. 이후 개발 접근 허용 범위는 D018을 따른다. 실제 이메일·OAuth 비밀값은 개인 환경에만 기록한다.

Google의 서명된 ID Token과 state·PKCE·nonce를 검증한 뒤 운영자가 명시한 초대 이메일을 처음 한 번 고정 issuer/sub에 연결한다. 이후 이메일 변경으로 계정이나 권한을 바꾸지 않고 활성 사용자·작업 공간 멤버십을 재확인해 서버 세션을 발급한다. 불특정 가입과 비밀번호 로그인은 제공하지 않는다. 두 사용자에게 공유할 자료 목록·기존 보호 근거 읽기 화면을 연결하며 Google 메일·Drive 접근 권한은 요청하지 않는다.

개발용 OAuth 클라이언트 JSON의 필수 항목·callback 일치와 개인 보관 권한은 확인했다. 실제 Google 로그인과 앱 DB 계정 연결은 대기 중이다. 합성 DB·서명·공급자 테스트는 실제 외부 로그인 검증과 구분한다. 작업 범위·HTTP/화면 계약은 [Google OAuth 작업 명세](../changes/google-oauth-workspace.md)에 기록한다. 공개 앱·main 병합 유예(D013)는 유지한다.

## D016 · B2C 브리핑 경험 · 2026-10-16

사용자 인터뷰와 연결 시안 승인을 반영한다. D006의 두 사용자는 초기 검증 참여자이며 최종 고객 범위가 아니다. 월10만 원은 개발·초기 검증 기준이며 B2C 이용 정책·수익 구조는 별도다. 상세 확정·제안·미정은 [제품 경험 인터뷰](../research/product-experience-interview.md)가 원본이다.

- 질문 우선 홈과 30초 브리핑을 기본으로 하고, 비교·변화·근거를 필요할 때 읽는다. 사실·엇갈린 주장·미확인을 구분하는 제품 목표는 근거와 분류 계약을 갖춰 구현한다. UI가 기존 AI 해석을 확인된 사실로 바꾸지 않는다.
- 목표 접근 방식은 비회원 브리핑 읽기·AI 질문부터 로그인이다. 공개 게시 저장소가 없는 현재 개발 앱은 질문 초안을 로그인 후 편집·명시 실행하는 첫 연결만 제공하며 비공개 자료는 공개하지 않는다. D015의 개발 초대·세션 경계는 유지한다.
- 홈은 최근 주목도와 개인화 이슈를 섞는다. 직접 관심사→저장/팔로우→질문→열람 순서를 초기 설계 기준으로 두되 정량 비율은 미정이다. 정치 성향이나 특정 주장 지지로 질문·열람을 해석하지 않는다.
- 중요한 새 사실·공식 결정·정정은 서비스 안 알림함을 우선한다. 공유 당시 브리핑·근거를 보존하고 최신판을 안내한다. 공개 댓글은 넣지 않는다. 이 기능들은 아직 backend가 없는 후속 범위다.
- 첫 실제 화면은 [브리핑 경험 명세](../changes/briefing-experience.md)를 따른다. 생성 중 선열람은 선택 원문의 정확 인용이며 AI 부분 답변/전체 검색 이력/검증된 사실이 아니다. 완료 검증된 AI 모듈은 브리핑으로 읽고 정확한 근거를 같은 화면에서 연다.

## 유지 규칙

- 결정은 날짜·근거·영향을 기록하고 이전 항목을 삭제하지 않는다.
- 작업 상태는 코드·테스트·PR·운영 검증 증거로만 바꾼다. PR 작성·문서 게시를 구현 완료로 표시하지 않는다.
- 계획 변경 PR에서 영향을 받는 요구사항·작업·Sites 요약을 함께 갱신한다. Sites 수동 반영 상태도 진행 기록에 남긴다.
- 실행 코드·데이터·서비스를 변경하기 전 관련 검토안을 확인한다. 구현 준비·폴더 연결·협업 문서 구성은 사용자 요청 범위다. 이미 승인된 범위의 통상 작업 때문에 같은 승인을 반복 요청하지 않는다.

## D017 · 브랜드·명시 테마·행동 시 로그인 · 2026-10-16

사용자는 이미지 생성 로고, 버튼으로 선택하는 다크모드, 우측 계정 메뉴의 명시 로그인과 질문 실행 등 필요한 행동에서만 로그인 화면으로 연결하는 방식을 요청했다. 정상 비회원 홈에는 반복 로그인 안내를 두지 않는다. 입력한 질문은 기존 제한된 임시 보관을 통해 로그인 후 편집 상태로 복원하고 사용자가 확인해 직접 시작한다. 자동 유료 실행은 추가하지 않는다.

기본 이용의 인증 안내를 줄이는 결정이며 기존 비공개 자료의 공개 허용은 아니다. 공개 브리핑 게시·읽기 계약은 후속이다. 로컬 기기에는 테마 선호만 보존하며 계정/질문 저장 경계는 유지한다. [작업 명세](../changes/brand-theme-entry.md)에 구현·검증 범위를 기록한다.
