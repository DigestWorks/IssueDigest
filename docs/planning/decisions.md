## D011 · 저장·검색·실행 엔진 확정 (2026-10-12)

사용자가 **PostgreSQL + pgvector + PydanticAI/DBOS**를 선택했다. A001~A003의 추천을 채택하며 PoC와 운영에 같은 엔진을 사용한다. 선택은 실제 한국어 검색 품질·중단 복구·월 비용 검증의 완료를 의미하지 않는다. 인증·운영 배치는 별도로 남긴다.

첫 구현은 [원문·인용 저장 기반](../changes/postgres-storage.md): PostgreSQL 18.6에 검증된 계약·불변 스냅샷·outbox를 한 트랜잭션으로 저장한다. 파일 원문, 검색 인덱스, Neo4j 투영, PydanticAI/DBOS 워커는 후속이다. 현재 의존성에 사용하지 않는 실행 프레임워크를 먼저 추가하지 않는다.

근거와 이관·한국어 검색·복구의 확인 기준은 [엔진 선택 기록](../research/engine-selection.md)에 둔다. 아래 이전 선택지는 당시 비교 이력으로 보존한다. 현재 후보로 다시 제시하지 않는다.

## 유지 규칙

- 결정은 날짜·근거·영향을 기록하고 이전 항목을 삭제하지 않는다.
- 작업 상태는 코드·테스트·PR·운영 검증 증거로만 바꾼다. PR 작성·문서 게시를 구현 완료로 표시하지 않는다.
- 계획 변경 PR에서 영향을 받는 요구사항·작업·Sites 요약을 함께 갱신한다. Sites 수동 반영 상태도 진행 기록에 남긴다.
- 실행 코드·데이터·서비스를 변경하기 전 관련 검토안을 확인한다. 구현 준비·폴더 연결·협업 문서 구성은 사용자 요청 범위다. 이미 승인된 범위의 통상 작업 때문에 같은 승인을 반복 요청하지 않는다.
