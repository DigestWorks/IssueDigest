## 공개 접근·브리핑의 다음 기반 · R1/R2/R4

- [ ] 현재 권한 상실 때 기표시 Canvas·자료 제목을 포함한 전체 상태를 정리한다. 현재 원문 미리보기/창의 권한 정리와 구분한다.
- [ ] 공개 브리핑 게시·읽기 모델을 설계한다. 게시 가능한 실제 자료의 이용권·검토·버전·철회와 비공개 원문/개인 질문 분리를 정의한다.
- [ ] 공개 데이터 계약을 구현한 뒤 비회원 읽기와 AI 질문 시 로그인·초안 이어가기를 결합 검증한다. 공유 개발 자료를 그대로 공개하지 않는다.
- [ ] 공개 이슈 범위·외부 탐색 범위·초기 AI 이용 정책의 미답변 항목을 확인한다. 현재 초대 정책을 불특정 가입/무제한 이용으로 임의 변경하지 않는다.

## 실제 탐색·점진 브리핑 · R2/R3/R4/R5/R6

- [ ] 최신 뉴스·공식 발표·당사자 발언·여론조사의 확보 가능성·이용 범위·현재 수집 성공/누락과 원문 대응을 확인한다. 법안 연결기는 승인 출처 하나로 재사용한다.
- [ ] 실제 평가 질문과 기대 근거로 한국어 어휘·정확 ID·벡터/필터/재순위화의 추가 효용을 검증한다. 현재 보호 문자 검색은 유지한다.
- [ ] 승인된 출처 탐색 도구를 현재 권한·예산·단계 저장/복구와 연결한다. 자료 부족·상충 자료·원문 내 지시·잘못된 주체/시점·수치 조건을 평가한다.
- [ ] 확인한 사실·엇갈리는 주장·미확인의 근거/분류 계약을 정의하고 검증된 AI 모듈부터 전달한다. 현재 원문 선열람과 완료 AI 결과를 부분 답변 완료로 오인시키지 않는다.
- [ ] 부분 갱신·수정·실패·취소·재접속에서 이전 결과·읽던 위치·열린 원문·질문 맥락을 보존한다. 중복 제출/불명확 유료 응답·워커 재시작·실행 버전 변경을 검증한다.
- [ ] 필요한 질문에서만 근거 있는 관계 탐색·Neo4j 투영을 구현하고 정정/삭제·재구축·복구를 검증한다. 관계도·이미지는 필요한 근거와 도구 계약이 있을 때 확장한다(R7).

## 관심 이슈·변화·공유·발견 · R1/R4/R6

- [ ] 개인 관심 이슈·질문 이력의 소유/접근·삭제/해제 모델을 설계하고 실제 저장한다. 현재 공유 브리핑 기록에 개인 소유 이름만 붙이지 않는다.
- [ ] 중요한 새 사실·공식 결정·정정을 비교하고 서비스 안 알림함·최신 전체 브리핑의 변경 표시를 연결한다. 기존 인용/결과를 덮어쓰지 않는다.
- [ ] 공유 당시 브리핑·근거를 보존하는 불변 공유본과 최신판 안내·공개 범위/철회를 구현한다.
- [ ] 실제 매체 관측 범위·기간·갱신시각·중복 제거·선정 이유로 최근 주목 이슈를 구성한다. 국민 여론이나 임의 인기 점수로 대체하지 않는다.
- [ ] 직접 관심사→저장/팔로우→질문→열람 신호의 우선순위, 혼합·감쇠·다양성·관심 없음·이력 해제·동의를 정하고 평가한다. 정치 성향·주장 지지를 추정하지 않는다.

## 출시 판정과 운영 · R1~R6

- [ ] B2C 이용량·비용·수익 정책을 정하고 실제 동시 비용 예약/정산·도구별 한도·취소/실패/재시도 비용을 검증한다. 월10만 원은 개발·초기 검증 상한이다.
- [ ] 원문·기준 DB·실행 이력의 외부 백업과 별도 환경 복원·검색 재구축을 검증한다. 서비스 분담 비용·공존 자원·정기 수집·비밀 설정을 확인한다.
- [ ] 실제 사용자 질문으로 정확 인용·오연결·자료 부족·이슈 이해·첫 유용한 결과/전체 완료 지연·비용을 평가한다. 초기 소수 검증을 전체 고객 품질로 일반화하지 않는다.
- [ ] 접근 거부·공개/개인 분리·복구·운영 조건의 증거로 첫 공개 여부를 판단한다. D013의 main/운영 게시 유예는 별도 승인 전 유지한다.

현재 재사용 기반은 원문·인용·저장/권한·Google 로그인·문자 검색·PydanticAI/DBOS 실행·생성 렌더러·후속 질문/취소/재열람이다. 구현된 항목을 다시 미완료로 나열하지 않으며 상세 제한·검증 시점은 [변경 명세](../README.md)와 [진행 기록](progress.md)에서 확인한다.
