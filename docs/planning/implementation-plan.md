# IssueDigest 구현 계획

2026-10-18 기준. IssueDigest는 질문에서 시작해 이슈의 맥락·쟁점·변화를 이해하는 B2C 브리핑 서비스다. [D016·D017·D019·D020·D021·D022](decisions.md)과 [제품 경험 인터뷰](../research/product-experience-interview.md)가 제품 방향의 원본이다. 이 문서는 현재 구현과 다음 구현을 구분한다. 두 사람의 공동 자료 검증을 최종 제품 구조로 확대하지 않는다.

## 제품 여정

1. 궁금한 질문을 입력하거나 실제 게시된 공개 브리핑을 읽는다. AI 질문은 홈 초안으로 이어가 로그인 후 편집·명시 제출한다. 최근 주목 이슈는 별도 관측 데이터가 필요한 후속이다.
2. 30초 요약으로 시작해 자료로 확인한 내용·엇갈리는 주장·미확인을 구분한다. 근거를 확인한 부분부터 보여 주고 나머지는 조사 중으로 표시한다.
3. 질문에 필요한 비교·시간 변화·반응·원문을 같은 맥락에서 열고 읽던 위치로 돌아온다. AI는 승인된 자료 탐색과 도구를 통해 필요한 표현을 선택한다.
4. 관심 이슈를 저장하고 중요한 새 사실·공식 결정·정정을 서비스 안 알림함에서 확인한다. 재방문 시 최신 전체 브리핑의 변경 부분을 본다.
5. 공유 당시 브리핑과 근거를 보존한 링크를 제공하고 최신판도 안내한다. 개인 질문·이력의 공개 범위는 별도 계약으로 다룬다.

이 여정 전체가 구현된 것은 아니다. 최근 이슈·개인화는 실제 관측 데이터와 이용 이력 정책이 필요하다. 공개 댓글은 제공하지 않는다. 질문·열람을 정치 성향이나 특정 주장 지지로 해석하지 않는다.

## 현재 구현과 경계

질문 우선 홈, 비회원 질문→로그인→편집 상태 복원, 명시 생성, 현재 권한의 저장 색인에서 서버가 질문에 맞는 최대5개 근거 검색/고정, 검증된 완료 브리핑과 정확 인용의 원문 열기, 후속 질문·취소·재접속·자동 저장/재열람을 연결했다. 헤더는 테두리 없는 테마·계정 아이콘이고 기본 메뉴는 브리핑·브리핑 기록이다. 질문만 제출하며 자료 선택·카탈로그·클라이언트 추천·자료 범위 선택기는 제공하지 않는다. 결과의 정확 인용에서 원문을 연다. 근거가 없으면 모델 호출 없이 자료 부족으로 끝낸다. 법안 기본 정보는 출처 한 종류이며 법안 전용 시작 행동은 제공하지 않는다.

과거 v1 완료 브리핑에서 seed 뒤에 추가된 근거도 현재 권한과 정확한 원문 연결·본문 동일성을 재검증해 기존 응답의 근거 ID로 열 수 있다. 이 호환 해석은 읽기 응답에만 적용하며 저장 결과·원문·이벤트를 변경하지 않는다. 일반 후속 질문은 부모의 실제 근거 전체를 고정하고, 새 v2/v3/v4 근거 불일치는 안전하게 거부한다.

현재 자료와 브리핑 기록은 초대된 초기 검증 참여자의 공유 자료 범위에 속한다. 개인 보관함이나 공개 피드가 아니다. 공개 브리핑은 독립 게시 저장소와 명시 권리/전체 내용 검토한 불변 복사본으로 분리했다(D020). 실제 목록·고정 버전/최신판 안내·정확 인용 재확인·일반 질문 초안을 연결했다. 첫 지원은 개별 확인된 한국정책브리핑 공공누리1유형 텍스트이며 사진/외부 저작물과 기존 private 실행은 공개하지 않는다. 독립 인수·개별 내용/이용 조건 검토 후1건 명시 게시와 개인 개발 HTTPS 반영·사후 백업 복원을 확인했다. 추천·개인 저장·변경 알림·사용자 고정 공유본은 후속이다. 생성 중에는 실제 단계 상태를 표시하며 검증된 AI 부분 결과 전달은 후속이다. 현재 AI의 해석을 UI가 확인된 사실로 승격하지 않는다.

현재 개인 개발 앱은 제품 소스 `1c0c5ed`의 새 private v4와 제한 한국어 검색을 사용한다. 기관의 주장·수치 귀속 및 목표·실적·전망 지침을 보완했으며 v2/v3의 지침·schema·유료 checkpoint/slot1과 과거 결과·공개v1/hash는 보존한다. AI 해석·세 분류·짧은 평가 설명·정확 원문을 기존 화면에서 읽는다. 운영자 명시 공식 자료 SDK는 유지하며 질문 중 자율 외부 탐색은 아니다. 자료13/인용37/검색27/공개1·기존 계정/세션을 보존하고 전체3,140개 검사·독립 검토·native6조합·전후 백업/별도 복원을 확인했다. 실제 모델3회 중 두 수치 응답은 부분 충족이고 없는 전국 여론 수치는 자료 부족으로 답했다. 귀속 분류·비교 결론·한계 설명은 다음 품질 개선 항목이며 원래20문항과 전체 정치 이슈/의미 품질은 미검증이다. 상세 증거·Sites 상태는 [진행 기록](progress.md)을 따른다.

완료율을 임의의 백분율로 계산하지 않는다. **완료**는 해당 단계의 코드·검증 증거가 있다는 뜻이며, **진행 중**은 일부 기반만 있다는 뜻이다. 개인 개발 적용과 운영 출시는 별도다. 각 단계는 필요한 부분부터 병행하며 아래 표의 순서는 제품 의존성의 우선순위다.

## 검증과 비용

인용의 정확한 위치와 주장 지지/진실을 구분하고, 여론조사·언론·온라인 반응을 별개로 표시한다. 생성 UI는 허용된 모듈·액션과 실제 근거를 서버에서 검증한다. 저장 결과 재열람·필터/정렬은 모델을 호출하지 않는다. 중복 제출·불분명한 유료 응답·취소 뒤 추가 호출·작업 복구와 계약 버전 변경을 검증한다.

월10만 원은 개발·초기 검증 상한이다. B2C 이용량·과금·수익 정책은 별도 설계한다. 실제 질문의 정확성·정보 부족·첫 유용한 결과/전체 완료 지연·비용을 측정하고 소수 검증 참여자의 결과를 전체 고객 성능으로 일반화하지 않는다. 백업은 저장 증거와 별도 환경 복원 증거를 함께 갖춰야 한다.

완료 상세와 과거 P0~P6 계획의 전개는 [진행 기록](progress.md), [이전 기록](archive.md), `docs/changes/`와 Git 이력(재편 전 기준 `d6d05f3`)에 보존한다. 과거 단계별 완료/미완료 목록을 현재 계획으로 중복 유지하지 않는다. 저장소가 결정 원본이며 Sites는 검증된 상태의 요약이다.

D022의 제한 한국어 검색·운영자 read-only 평가와 v4는 실제 모델3회·native 화면 인수·개인 개발 갱신·PR36·Sites v58까지 확인했다. 두 실제 수치 응답의 의미 품질은 부분 충족이며 운영 출시는 유예한다. 실제 고정 검색34문항의 집계와 남은 오류는 [D022](decisions.md)·[평가 안내](../../tests/evaluation/README.md)를 따른다. 기존20문항은 미실행이다.
