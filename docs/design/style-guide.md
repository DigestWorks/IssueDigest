# IssueDigest 스타일 가이드

- 상세 규칙과 견본: 앱의 `/style` 페이지 (`apps/web/app/routes/style.tsx`)
- 규칙 데이터: `apps/web/app/design/guide.ts`
- 토큰: `apps/web/app/design/palette.ts`(색), `apps/web/app/design/tokens.ts`(불투명도·글자·모션), `apps/web/app/app.css`(UI 색)

규칙과 견본은 코드의 토큰을 그대로 렌더링하는 `/style` 페이지를 기준으로 한다. 이 문서에는 정체성 기준과 결정 기록만 둔다.

## 정체성 기준: 출처가 붙은 조사 기록

IssueDigest 의 화면은 에이전트가 한국 사회 데이터를 조사한 기록이다.

- 측정 기록: 화면의 모든 표시는 온톨로지에서 찾은 노드·관계·값 하나에 대응하고 출처를 가진다.
- 조사 과정 기록: 무엇을 찾았는지와 함께 어떤 순서로 찾았는지가 화면에 남는다.
- 불확실성 표시: 명시된 관계는 실선, 모델이 추론한 관계는 점선, 근거가 없으면 유보 상태로 그린다.
