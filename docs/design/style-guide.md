# IssueDigest 스타일 가이드

- 상세 규칙과 견본: 앱의 `/style` 페이지 (`apps/web/app/routes/style.tsx`, `apps/web/app/style/specimens.tsx`)
- 규칙 데이터: `apps/web/app/design/guide.ts` (`CHAPTERS`, `RETIRED`)
- 토큰: `apps/web/app/design/tokens.ts`(테마·불투명도·글자·모션·홀로그램·효과·바닥 조명), `apps/web/app/design/palette.ts`(데이터 색)
- 기준 화면: 3D 지도 `/map` (`apps/web/app/stage/schematic/map/*`), 결과 패널 (`apps/web/app/stage/schematic/*`)
- 적용 화면: 메인 화면 `/` (`apps/web/app/main/*`: 조사 기록, 그래프·지도·패널 스테이지)

규칙과 견본은 코드의 토큰을 그대로 렌더링하는 `/style` 페이지를 기준으로 한다. 이 문서에는 정체성 기준, 원칙 요약, 결정 기록, 폐기 요약을 둔다.

## 정체성 기준: 출처가 붙은 조사 기록

IssueDigest 의 화면은 에이전트가 한국 사회 데이터를 조사한 기록이다.

- 측정 기록: 화면의 모든 표시는 온톨로지에서 찾은 노드·관계·값 하나에 대응하고 출처를 가진다.
- 조사 과정 기록: 무엇을 찾았는지와 함께 어떤 순서로 찾았는지가 화면에 남는다.
- 불확실성 표시: 명시된 관계는 실선, 모델이 추론한 관계는 점선, 근거가 없으면 유보 상태로 그린다.

## 원칙 요약 (2026-10-11 지도 기준 재정의)

3D 지도에서 여러 차례 피드백으로 확정한 표현을 제품 전체의 스타일로 삼는다. 2026-10-12 메인 화면을 이 스타일로 처음부터 다시 만들었다.

| 장 | 요약 |
| --- | --- |
| 핵심 원칙 | 데이터 색은 답과 관련된 부분에만 쓰고 나머지는 중립색으로 그린다. 주황은 선택·초점에만 쓴다. 표시에는 좌표·축척·출처 같은 측정 정보를 함께 적는다. |
| 장면 | 어두운 모드가 기본이고 밝은 모드로 전환할 수 있다. 지도 중심 바닥을 원형으로 밝히고, 격자는 중심에서 멀어질수록 옅어진다. |
| 선과 주석 | 위계는 불투명도 네 단계(100·66·33·11%)로 만든다. 층 묶음은 맨 위 외곽선만 굵게 그린다. 지도에는 꺾쇠·경위도 눈금·축척·출처를 적는다. |
| 색 | 데이터 팔레트는 OKLCH 여섯 색이다. 밝은 모드 주황은 흰 바탕 대비 기준으로 선·점과 글자 값을 따로 둔다. |
| 부피 | 높이는 수평 외곽선 층의 수로 나타낸다(층 간격 0.18). 선택하면 층 간격이 최대 1.5배로 벌어진다. |
| 효과 | 아웃포커스, 층 색 번짐, 화면 색수차, 바닥 조명만 쓴다. 발광·화면에 보이는 광원·글리치는 쓰지 않는다. |
| 글자 | Pretendard 와 고정폭 보조 글자. 제목은 굵기 200·자간 0.06em 이고, 제목 위에 「번호 \| 보조 글자」 줄, 아래에 주황 시작점이 있는 머리선을 둔다. |
| 화면 고정 주석 | 네 모서리에 제목, 조작, 범례·출처, 카메라 수치를 둔다. 버튼은 글자와 사각점으로 만든다. |
| 패널 | 선과 점으로 만든 틀, 번호 잔상, 데이터 색 계열. |
| 지도 | 선택 시 외곽선 추적·지시선·주석, 눕거나 서는 지역 이름, 방위 고리, 세 가지 보기. |
| 그래프 | 노드는 정사각 판 층 묶음, 유형은 보조 글자, 색 없음(초점만 주황). 명시 관계 실선·추론 관계 점선, 탐색 경로는 한 번 그려지고 단계 번호가 남는다. |
| 조사 기록 | 메인 화면 왼쪽 대화 열. 질문, 답, 번호 붙은 탐색 단계(선택하면 스테이지 초점 이동), 출처를 쌓는다. |
| 모션 | 점 → 선 → 글자 순서. 지도는 가운데에서 펼쳐지고(약 1.3초) 층이 아래에서 위로 펼쳐진다. 등장과 선택 표시는 한 번만 재생한다. |
| 조작 | 대상 클릭은 선택, 배경 클릭·Esc 는 해제, 4px 넘게 끌면 회전·이동으로 본다. |

## 폐기한 규칙

전체 목록과 대체 규칙은 `/style` 의 「폐기한 규칙」과 `guide.ts` 의 `RETIRED` 에 있다.

- 흰 배경 → 어두운 모드 기본(흰 장면 값은 밝은 모드에 남음)
- 「색상은 데이터에만 쓴다」, 무채색 선택 표시 → 새 색 원칙, 주황 선택 표시
- 불투명한 압출 지역과 그림자 → 수평 층 묶음
- 흰색 차트 계열에 주황 강조 계열 → 데이터 색 계열
- 색수차 금지 → 지도에 한해 허용
- 반복 주사선, 빛무리 등장 → 삭제
- 무광 기호 노드 → 정사각 판 층 묶음, 유형은 보조 글자(2026-10-12 메인 화면 재작성)
